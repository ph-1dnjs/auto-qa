처음 시작하기

            
AutoQA 사용 가이드

          

          
        

        

          

            1. 시나리오 생성 페이지로 이동
            
`시나리오 생성` 메뉴에서 대상 URL을 입력하고 화면을 열어 액션을 추출하거나 직접 시나리오를 편집합니다.

          

          

            2. 시나리오 저장
            
작성한 시나리오는 추출기 또는 시나리오 생성 페이지에서 바로 저장할 수 있습니다.

          

          

            3. QA 실행 페이지에서 실행
            
`QA 실행` 메뉴에서 대상 URL과 시나리오 파일을 준비한 뒤 실행하면 진행 상태와 결과를 확인할 수 있습니다.
