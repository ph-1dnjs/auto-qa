처음 시작하기

            
AutoQA 사용 가이드

          

          
        

        

          

            1. 테스트 대상 URL 입력
            
`https://...` 형식의 서비스 URL을 입력한 뒤 필요하면 워커 수와 Headless 옵션을 조정합니다.

          

          

            2. 시나리오 준비
            
직접 Markdown 시나리오를 작성하거나 `시나리오 추출`로 화면에서 액션을 수집하고, `시나리오 저장`으로 `.md` 파일로 내보낼 수 있습니다.

          

          

            3. QA 실행
            
`QA 실행`을 누르면 전체 시나리오 수, 통과/실패 수, 진행률이 즉시 갱신되고 아래 Preview 영역에서 실제 테스트 화면을 볼 수 있습니다.

          

          

            4. 결과 확인
            
오른쪽 실행 결과 패널에서 시나리오별 상태를 확인하고, 완료 후 `HTML 리포트 열기`로 상세 리포트를 확인합니다.

          

          

            5. 추천 시작 순서
            
처음에는 `baseUrl 입력 -> 시나리오 추출 -> 시나리오 저장 -> QA 실행` 순서로 사용하면 가장 빠르게 익숙해집니다.
