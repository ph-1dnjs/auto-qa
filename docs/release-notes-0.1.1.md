# Release 0.1.1

Previous version: 0.1.0

## Summary

- 사용자에게 보이는 주요 변경사항을 2-4줄로 정리해 주세요.

## Changes

- feat: 사용 가이드 모달 추가 및 관련 기능 구현 - 사용 가이드 버튼 추가 - 가이드 모달의 열기/닫기 기능 구현 - 가이드 모달의 초기 표시 상태를 로컬 스토리지에 저장 - 가이드 모달 스타일 추가
- feat: QA 진행 상황 미리보기 기능 추가 및 UI 개선 - QA 시나리오 진행 상황을 실시간으로 미리 볼 수 있는 기능 추가 - UI에 미리보기 섹션 및 관련 요소 추가 - 시나리오 아코디언 토글 기능 구현 - 진행 상황에 따른 미리보기 이미지 및 상태 업데이트 기능 추가
- feat: 시나리오 저장 기능 추가 및 UI 개선 - 시나리오 저장을 위한 ipcMain 핸들러 추가 - 시나리오 저장 버튼 및 관련 UI 요소 추가 - 시나리오 미리보기 및 카운트 기능 개선 - 레이아웃 및 스타일 조정으로 사용자 경험 향상
- feat: 시나리오 추출 기능 추가 및 UI 개선 - 시나리오 추출 버튼을 추가하고 UI를 개선함 - 추출된 시나리오를 텍스트 영역에 추가하는 기능 구현 - 추출기 웹뷰를 포함한 새로운 섹션 추가 - 관련된 CSS 스타일을 추가하여 UI를 개선함
- feat: 시나리오 파싱 및 리포팅 기능을 포함한 Playwright 기반 자동 QA 실행기 구현

## Notes

- GitHub Release 본문에 이 문서를 붙여 넣어 사용할 수 있습니다.
- 자동 업데이트 배포 시 Windows는 `latest.yml`, macOS는 `latest-mac.yml`도 함께 업로드되어야 합니다.
